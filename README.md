
# School App Projects - Lab 8

## Introduction
This repository contains two ASP.NET Core
applications developed using the Code First
approach with Entity Framework Core.

## Exercise 1: Razor Pages Application

Project: SchoolAppCoreRazor

Technologies:
- ASP.NET Core Razor Pages
- Entity Framework Core
- SQL Server
- Code First Approach

Features:
- Manage Students
- Manage Courses
- Manage Instructors
- Manage Enrollments
- Manage Departments
- CRUD operations

### How to Run
1. Open SchoolAppCoreRazor in Visual Studio.
2. Configure the SQL Server connection string.
3. Run Update-Database if needed.
4. Press F5 to run the application.

## Exercise 2: MVC Application

Project: SchoolAppCoreMVC

Technologies:
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Code First Approach

Features:
- MVC Controllers and Views
- CRUD operations
- Database management with Code First

### How to Run
1. Open SchoolAppCoreMVC in Visual Studio.
2. Configure the SQL Server connection string.
3. Run Update-Database if needed.
4. Press F5 to run the application.

## Conclusion
This lab demonstrates how to build ASP.NET Core
applications using Razor Pages and MVC with
Entity Framework Core Code First.
